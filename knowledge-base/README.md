## 1. 一句话流程（每次都走这条线）

```
认领授权任务 → 填 scope.yaml（仅授权资产）→ safe_exec 包裹扫描
   → 只读取、不入侵 → 生成草稿（人工复核）→ 平台手动提交 → 停止一切探测
```

## 2. 铁律（违反任一条即停手）

1. **只扫 scope.yaml 里的域名/IP**，越权目标会被 `scope_validator` 拒绝（验证过：out-of-scope.example→DENY）。
2. **不登录、不爆破、不发 payload、不拖库、不改数据、不 DoS。**
3. **AI 只出草稿，永不替你点"提交"。**
4. **提交后立刻停止对该目标的一切探测。**
5. 任何异常/犹豫 → 跑 `kill_switch.py` 一键熔断。
