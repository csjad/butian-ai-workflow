# 01 · 环境搭建与工具链

> 目标：让 `butian-ai-workflow` 的外置安全工具能在本机跑起来。
> 本机环境：Windows 10+，C/E 盘空间紧张，沙箱对删除/解压有限制。

---

## 1.1 Go 工具链（关键结论先说）

**用本机已有的 Go 1.24.6，不要新装。**

| 路径 | 状态 | 说明 |
|---|---|---|
| `E:\pentest\tools\go` | ✅ **用这个** | 用户预装 Go 1.24.6，stdlib 完整（129MB），GOROOT 已冻结 |
| `E:\go126\go` | ❌ **禁用** | 沙箱解压截断，stdlib 残缺（仅 30MB，缺 `math/bits`/`text/template`），不可用 |
| `E:\go` (旧 1.22.5) | ❌ 太旧 | `@latest` 工具要求 go≥1.25/1.26，编译报 `version mismatch` |

**必设环境变量（每次跑 go 前 export）：**

```bash
export PATH="$PAT$TOOLS_ROOT/tools/go/bin"        # go 本体
export GOTOOLCHAIN=local                           # 禁止自动下载新版工具链
export GOSUMDB=off                                 # 本机无法访问 sum.golang.google.cn
export GOPROXY="https://goproxy.cn,direct"         # CN 镜像，go.dev 直连失败
export GOMODCACHE="$GOMODCACHE"
export GOCACHE="$GOCACHE"
```

> 注意：`GOROOT`/`GOCACHE`/`GOSUMDB` 是**系统级冻结变量**，`go env -w` 会被拒（Access is denied）。
> 不要在 E:\ 根目录写日志——会 Permission denied，日志写到工作区目录。

**构建命令模板（单工具，避免卡死）：**

```bash
export PATH="$PAT$TOOLS_ROOT/tools/go/bin"
export GOTOOLCHAIN=local GOSUMDB=off
export GOPROXY="https://goproxy.cn,direct"
export GOMODCACHE="$GOMODCACHE" GOCACHE="$GOCACHE"
go install github.com/projectdiscovery/katana/cmd/katana@v1.4.0
```

> ⚠️ **本环境怪象**：`go install` 二进制落盘后会卡在收尾不退出（疑似缓存死锁），约 10 分钟不返回。
> 判定方法：看 `gopath/bin\<tool>.exe` 是否已生成且能跑；生成后直接停掉后台任务即可，已落盘的二进制不受影响。

## 1.4 致命坑：httpx 同名冲突（已修复）

Python venv 里有同名 `httpx` 包 CLI，原 `safe_exec.py` 用 `shutil.which` 会**误调 Python 版**而非 Go 版，导致漏洞扫描静默失效。

**修复**：`safe_exec.py` 加 `find_tool()`，解析顺序：
```
BUTIAN_TOOLS_BIN  →  go env GOBIN  →  PATH（最后）
```
并设用户环境变量：`BUTIAN_TOOLS_BIN=$(go env GOPATH)/bin`

验证：`httpx` 现正确指向 `gopath\bin\httpx.exe`（ProjectDiscovery 版）。
