# 05 · 工具速查与故障排查

> 跑工具卡住时翻这一页。

---

## 5.1 通用调用方式（永远经 safe_exec）

```bash
PY="python"
SK="$BUTIAN_ROOT"
export BUTIAN_TOOLS_BIN="$(go env GOPATH)/bin"
$PY $SK/scripts/safe_exec.py --tool <tool> --target <domain> --scope $SK/config/scope.yaml -- <args>
```

## 5.2 各工具命令模板

### subfinder（子域枚举）
```bash
$PY $SK/scripts/safe_exec.py --tool subfinder --target example-a.com \
  --scope $SK/config/scope.yaml -- -d example-a.com -all -silent -o out/subfinder.txt -rl 10
```

### httpx（存活 + 响应头）
```bash
# 存活
$PY $SK/scripts/safe_exec.py --tool httpx --target example-a.com \
  --scope $SK/config/scope.yaml -- -l out/subfinder.txt -silent -o out/alive.txt -timeout 10 -retries 1 -rl 50 -title -tech-detect
# JSON 响应头（用于安全头分析）
$PY $SK/scripts/safe_exec.py --tool httpx --target example-a.com \
  --scope $SK/config/scope.yaml -- -l out/subfinder.txt -silent -o out/json.txt -json
```

### naabu（端口，限速）
```bash
$PY $SK/scripts/safe_exec.py --tool naabu --target example-a.com \
  --scope $SK/config/scope.yaml -- -list out/subfinder.txt -top-ports 100 -silent -o out/ports.txt -rate 100 -retries 1 -timeout 1000
```

### katana（爬虫，仅非后台）
```bash
$PY $SK/scripts/safe_exec.py --tool katana --target example-a.com \
  --scope $SK/config/scope.yaml -- -list seeds.txt -d 2 -silent -o out/urls.txt -rl 10 -timeout 10
```
> 种子文件只放 www/h5，不要放 subadmin/superadmin。

### nuclei（模板检测，非侵入）
```bash
# 先更新模板（gitee 镜像或官方）
$PY $SK/scripts/safe_exec.py --tool nuclei --target example-a.com \
  --scope $SK/config/scope.yaml -- -update-templates
# 跑非侵入模板
$PY $SK/scripts/safe_exec.py --tool nuclei --target example-a.com \
  --scope $SK/config/scope.yaml -- -l out/alive.txt -silent -o out/nuclei.txt
```

### gau / waybackurls（历史 URL）
```bash
echo example-a.com | gau >> out/historical.txt
```

### nmap（端口扫描补充，限速 + 授权闸门）
```bash
# 自检（不扫描，验证发现 + 闸门）
$PY $SK/scripts/safe_exec.py --tool nmap --target example-a.com \
  --scope $SK/config/scope.yaml -- --version
# 真扫（授权范围内，强制限速）
$PY $SK/scripts/safe_exec.py --tool nmap --target example-a.com \
  --scope $SK/config/scope.yaml -- -Pn --top-ports 100 --max-rate 50 -T2 -oN out/nmap_ports.txt
```
> nmap 发现路径在 `config/tools.yaml` 的 `tools.nmap.extra_paths`（本机 `C:\Program Files (x86)\Nmap`）。
> 必须限速（`--max-rate 50 -T2`）；仅扫授权目标；`-Pn` 跳过主机发现更温和。

### Burp Suite（仅上游代理抓包，不自动驱动）
```bash
# 1) 先开 Burp，确认监听 127.0.0.1:8080（默认）
# 2) 临时开代理，让 httpx/nuclei 等流量进 Burp 抓包
export BUTIAN_PROXY_AUTO=1
$PY $SK/scripts/safe_exec.py --tool httpx --target example-a.com \
  --scope $SK/config/scope.yaml -- -l out/subfinder.txt -silent
# 或显式指定代理地址（覆盖 tools.yaml）
export BUTIAN_PROXY="http://127.0.0.1:8080"
```
> 默认不走代理；只有设了 `BUTIAN_PROXY_AUTO=1` 或 `BUTIAN_PROXY=<url>` 才注入 `-proxy` 与 `HTTP_PROXY`。
> Burp 没开时设了代理会导致连接失败——所以默认关闭最安全。深度自动驱动 Burp 需 Pro + Montoya 扩展，本次不做。

## 5.3 故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `compile: version "go1.24.6" does not match` | Go 太旧 | 用 `E:\pentest\tools\go` 1.24.6 + `GOTOOLCHAIN=local` |
| `requires go >= 1.25/1.26` | 工具 @latest 要新 Go | 钉旧版：`katana@v1.4.0`、`naabu@v2.6.1`、`gau@v2.2.4` |
| `go install` 卡死不退出 | 二进制已落盘但收尾死锁 | 看 `gopath/bin\<tool>.exe` 存在即停任务，二进制可用 |
| `httpx` 调到 Python 版 | venv 同名冲突 | 已修 `find_tool()` + `BUTIAN_TOOLS_BIN`，无需再处理 |
| `Access is denied` (go env -w) | 系统变量冻结 | 改用命令行 `export`，别用 `go env -w` |
| dalfox 装不上 | github 被墙 + 镜像不代理 | 放弃，nuclei 覆盖 XSS |
| 日志 Permission denied (E:\ 根) | 沙箱限制 | 日志写到工作区目录 |
| `safe_exec` 对任意目标都拒（含授权目标） | `scope.yaml` 的 `time_window` 已过期 | 把 time_window 末值延到当前日期之后（须对齐补天真实授权期） |
| nmap 报 `executable not found` | `tools.yaml` 的 `extra_paths` 路径不对 | 改为本机 Nmap 真实安装目录（如 `C:\Program Files (x86)\Nmap`） |
| `naabu` 静默 `EXIT=1` 无任何输出（对商业/云目标） | 沙箱拦截出站 SYN 探测（子进程被掐断） | 改用 nmap `-sT -Pn` connect 扫描补救；或仅依赖被动端口证据（httpx 80/443 + katana 非标端口如 `:462`/`:4436`）。naabu 对教育网等网络通时可用，商业目标常受限 |
| `safe_exec` 调 nmap/burp 报 `TypeError: write() argument must be str, not None` | `subprocess.run(text=True)` 遇非 UTF-8 输出使 `r.stdout` 变 None | 已修：`subprocess.run(..., errors="replace")`，写回前用 `r.stdout or ""` |
| httpx v1.10 silent 模式 `-sc/-cl/-ct` 不显示状态码（输出只有 `url [GET]`） | v1.10 输出格式兼容问题 | 用 `-mc "200"` 状态码过滤：输出的行即匹配状态码的 URL，直接判可访问性；或 `-json` 调试 |
| gau v2.2.4 报 `EXIT=2` 打印帮助 | 该版本不支持 `-subs`/`-o`/`-retries` flag（Go flag 包要求 flag 在位置参数前，未知 flag 即报错） | 用 stdin 批量：`cat domains.txt \| gau`（配合 safe_exec `--stdin-file`）；单域用 `gau domain`（无额外 flag） |
