# 法律与授权规则（legal.md）

> 本文件为强制约束，任何 Agent / 脚本 / 用户请求均不可推翻。

## 1. 授权是前提

- 仅对**已获书面或明确授权**的资产发起任何流量。
- 授权范围以 `config/scope.yaml` 为准，且必须通过 `scope_validator.py` 校验。
- 授权缺失、过期、范围不清 = 禁止操作。

## 2. 禁止行为（绝对）

以下行为无论何种理由都**不得执行**：

- 对未授权目标扫描 / 探测 / 利用；
- 自动向任何 SRC / 补天 / 漏洞平台提交报告或 Issue；
- 拖库、下载大量数据、窃取凭据；
- 拒绝服务（DoS / 高并发压测导致目标不可用）；
- 横向移动、权限提升以触及授权范围外资产；
- 在目标系统留后门、WebShell、持久化；
- 篡改、删除、破坏目标数据（含数据库写、文件写、配置改）；
- 绕过或禁用安全闸门、审计日志、熔断开关。

## 3. 平台规则

- 遵守目标 SRC 平台的scope、禁止测试项、提交格式。
- 不得测试第三方系统（如目标依赖的 CDN、认证服务商），除非其也在授权范围内。

## 4. 数据保护

- 扫描产物（recon/、findings/、reports/、*.db）含潜在敏感信息，**严禁提交到公开仓库**。
- API Key、授权文件走环境变量 / `.gitignore`，不入库。

## 5. 责任

- 使用者对每一次扫描承担法律责任。
- AI 结论仅供参考，提交前须人工复现与确认。
- 误用造成的后果由使用者自行承担，本工具作者不担责。
